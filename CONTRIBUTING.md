# Contributing

Use Windows PowerShell 5.1. Keep changes focused, explain the resulting behavior, and run the offline tests listed in the README. Include desktop validation for changes to COM wallpaper application or scheduling. Tests must use synthetic quotes and mocked services, never personal API keys or downloaded collections.

Preserve readability, rejection of unsuitable quotes, repeat avoidance, rollback, and API caching. Change the versioned assessment cache whenever the model or rubric changes. Review provider attribution and terms before adding an integration. Do not commit runtime data, logs, screenshots containing personal desktop information, or historical backups.

Report bugs with Windows version, command, sanitized error, and reproduction steps. Do not attach credentials, full local metadata, or user environment exports. Contributions are licensed under the project's MIT license.
